# TensorTonic Solutions

This repository contains implementations for machine learning, statistics, and linear algebra problems from [TensorTonic](https://www.tensortonic.com).

## Overview

Each directory corresponds to a problem from TensorTonic and holds code written to implement core mathematical and algorithmic concepts without relying on high-level shortcuts unless specified by the problem.
